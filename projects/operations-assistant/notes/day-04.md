# Day 4 — add grounded answer templates and execute their checks

I added an answer layer only after the approved tools had stable evidence IDs. It uses fixed templates over the tool response, carries the structured claims alongside the prose and cites the exact evidence ID. Empty denominators are written as “not calculable”, not 0%.

The comparison can identify the largest reduction in on-time completion count, but it explicitly avoids calling that region a cause. Different cohorts and one fixed snapshot do not support that conclusion.

I also added four executable grounding cases and a tampering test. They check exact claims, evidence identity and disclosure rules. This is still deterministic reporting, not AI inference. The evaluation harness is intentionally in place before a local model adapter so later generated answers can be judged against the same evidence.
